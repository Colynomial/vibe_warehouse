# Dashboard Builder — Initial Thoughts

## Twee Sporen

### Spoor 1: Onze Portal (MVP)
Wij bieden een standaard data-portal waar klanten hun data zien:
- Tabellen met filters
- Basis grafieken (bar, line, pie)
- Export (CSV, Excel)
- Gebouwd in React, onderdeel van het platform

### Spoor 2: Vibe-Coded Dashboards (differentiator)
Klanten bouwen eigen dashboards via vibe coding (zie [feature-vibe-coding](../feature-vibe-coding/)).
Dit is de echte waarde — wij leveren data, zij bouwen wat ze willen.

## MVP Portal Features
- [ ] Lijst van beschikbare datasets (materialized views)
- [ ] Tabel-view met paginatie, sortering, filtering
- [ ] Simpele chart builder (kies X-as, Y-as, chart type)
- [ ] Opslaan van "saved views" per user
- [ ] Export naar CSV
